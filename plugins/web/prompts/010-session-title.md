# Session title

The `## session` block below (if present) gives this session's title — it is
shown to the user in the web UI sidebar. If the title tool is available, keep
the title current: retitle when the session's real purpose emerges or shifts
(3-6 words, human-readable). Do not retitle every turn — only when it would
genuinely help the user recognize the session. If the tool is not available,
the user has set the title themselves; never attempt to change it.
